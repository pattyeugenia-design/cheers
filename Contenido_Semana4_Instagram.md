## Lunes — Carrusel: "Pago único, no suscripción"

Formato: carrusel explicativo, 6 slides. El ángulo de "fatiga de suscripciones" es fuerte para 2026 — este post no vende con urgencia, explica el modelo con calma.

**Slide 1 (portada)**
> Una cosa que NO tiene Cheers: suscripción mensual ✦

**Slide 2**
> Cheer — $0, para siempre
> 1 celebración activa, hasta 3 invitados. Sin tarjeta.

**Slide 3**
> Super Cheer — $9 USD, una sola vez
> Por celebración. Hasta 10 invitados y todo desbloqueado para ese evento.

**Slide 4**
> Extra Cheer — $49 USD, una sola vez, para siempre
> Todo ilimitado, en todas las celebraciones que crees, para siempre.

**Slide 5**
> Pagas una vez. No hay renovación, no hay cargo cada mes, no se te olvida cancelar nada.

**Slide 6 (cierre / CTA)**
> Resuelto una vez, no cada mes ✦
> Créala gratis — link en bio

**Caption sugerido:**
```
Ya tenemos suficientes suscripciones que se nos olvida cancelar. Cheers no es una más.

Pagas una vez (si es que pagas) y ya. Sin renovación, sin sorpresas en el estado de cuenta. Link en bio ✦

#cumpleaños #posada #quinceañera #despedidadesoltera #fiestasmexicanas
```

## Miércoles — Reel: comparación rápida de planes

Formato: texto animado sobre fondo degradado de marca, sin voz ni rostro. Formato tabla que se arma en pantalla. 12-15 segundos.

**Guion (texto en pantalla, aparece por bloques):**

| Tiempo | Texto sobreimpreso |
|---|---|
| 0-2s | "¿Cuál plan de Cheers es para ti?" |
| 2-6s | "Cheer — gratis / 1 evento / 3 invitados" |
| 6-10s | "Super Cheer — $9 una vez / 1 evento / 10 invitados" |
| 10-14s | "Extra Cheer — $49 una vez / eventos ilimitados / para siempre" |
| 14-15s | "Link en bio ✦" |

**Caption sugerido:**
```
Casi siempre con el plan gratis alcanza. Si no, aquí está lo que desbloquea cada uno, sin letras chiquitas.

Link en bio ✦
```

Música sugerida: tendencia actual, ritmo constante para acompañar los cortes de tabla.
